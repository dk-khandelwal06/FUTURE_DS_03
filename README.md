## 🔍 Project Overview

College events such as **workshops, seminars, and cultural programs** play a vital role in enhancing student engagement and campus life.  
However, collecting feedback is only useful when it is **properly analyzed and converted into actionable insights**.

This project focuses on analyzing **student feedback data** collected after college events to understand:
- Overall satisfaction levels
- Strengths and weaknesses of events
- Student sentiment toward different aspects of events
- Areas where future events can be improved

The project combines **numeric analysis**, **sentiment analysis**, and **data visualization** to support **data-driven decision-making** for event organizers.

---

## 🎯 Objectives

The key objectives of this project are:

- 🧹 Clean and prepare raw student feedback data  
- ⭐ Analyze ratings to evaluate satisfaction levels  
- 🧠 Perform sentiment analysis on feedback comments  
- 🔍 Identify patterns, trends, and correlations in the data  
- 📈 Visualize insights using clear and meaningful charts  
- 💡 Provide actionable recommendations for improving future college events  

---

## 🗂 Dataset Description

The dataset contains feedback collected from students after attending various college events.

### Key Features:
- **Event Name / Course Name**
- **Feedback Questions**
- **Average Score**
- **Percentage Score**
- **Weightage Values**
- **Derived Satisfaction Metrics**

The dataset was carefully cleaned and transformed to ensure accuracy and consistency before analysis.

## 🔬 Methodology

The project follows a structured, step-by-step data science workflow:

1️⃣ **Data Cleaning & Preparation**  
- Handled encoding issues  
- Cleaned column names  
- Converted mixed-format values into numeric data  

2️⃣ **Exploratory Data Analysis (EDA)**  
- Rating distributions  
- Event-wise and department-wise analysis  
- Initial trend identification  

3️⃣ **Numeric Analysis**  
- Average and weighted score calculations  
- Comparison across courses and events  

4️⃣ **Sentiment Analysis**  
- Sentiment scoring based on feedback logic  
- Categorization into Positive, Neutral, and Negative sentiments  

5️⃣ **Correlation Analysis**  
- Relationship between ratings and sentiment scores  

6️⃣ **Visualization & Reporting**  
- Clear charts and plots  
- Insights summarized in a professional report

## 💡 Key Insights

- Most college events received **positive feedback**, indicating good overall satisfaction  
- Academic and workshop-based events generally scored higher  
- Sentiment trends aligned strongly with numeric ratings  
- Certain departments showed higher engagement levels  
- Recurring improvement areas included **event timing, interaction, and structure**

---

## ✅ Recommendations

Based on the analysis, the following recommendations are suggested:

- 🕒 Optimize event schedules based on student availability  
- 🎤 Increase interaction through Q&A sessions and activities  
- 📋 Regularly analyze feedback to improve event planning  
- 🎯 Customize events to suit different departments and interests  
- 🔄 Use feedback loops for continuous improvement
